; fui_font_text - the 5 x 7 class font of the colour faces.
;
; Source of components/fractonica_ui/src/fui_font_text.c. Edit a glyph here,
; then run  tools/genfont.py  (or `make fonts` in sim/). Never edit the .c.
;
; A glyph is "@ <code point> [y=<row>]" and its rows: '#' ink, '.' blank.
; <code point> is 'c' for ASCII or U+XXXX. Rows start at the font's `top` row
; unless y= says otherwise; rows not given are blank. The width is that of the
; longest row (1..8). "w=<n>" alone makes a blank glyph n columns wide.
;
; The cell is 10 rows: row 0 is headroom (superscripts start there), rows 1..7
; hold capitals and digits, rows 8..9 descenders. Lowercase x-height is rows
; 3..7. Digits are all 5 wide so numbers do not jitter as they count.
