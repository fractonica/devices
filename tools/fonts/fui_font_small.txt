; fui_font_small - the 3 x 5 class dot font of the one-bit face (DESIGN.md S11).
;
; Source of components/fractonica_ui/src/fui_font_small.c. Edit a glyph here,
; then run  tools/genfont.py  (or `make fonts` in sim/). Never edit the .c.
; The format is explained at the top of fui_font_text.txt.
;
; The cell is 8 rows: row 0 is headroom (superscripts), rows 1..5 hold
; capitals and digits, rows 6..7 descenders. Lowercase x-height is rows 2..5.
; The face draws the count at 2 px per dot. As DESIGN.md asks, the Greek unit
; letters take the room they need: eta is 4 x 7, iota 2 x 5, nu and pi 5 x 4.
; Shapes that would collide are kept apart on purpose: 0 is square, O is
; round; theta is round with a bar, 8 is square; epsilon is round, E square;
; delta is a hook and a stem over a closed bowl, epsilon is open on the right
; (they differed by two pixels once, and "δ#5 ε#2" sit side by side);
; '#' is 5 wide (at 3 it reads as H or N, and every ordinal carries one).
